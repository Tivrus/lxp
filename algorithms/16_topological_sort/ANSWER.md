# Топологическая сортировка (алгоритм Кана)

1. Считаем входящую степень каждой вершины: A=0, B=0, C=2, D=1, E=2, F=1.
2. Кладём в очередь вершины со степенью 0: A, B.
3. Берём вершину из очереди, добавляем в ответ и уменьшаем степень её соседей. Сосед, у которого степень стала 0, идёт в очередь.

Порядок: A -> B -> C -> D -> E -> F.

Если добавить ребро F -> B, появляется цикл B -> C -> E -> F -> B (и B -> D -> E -> F -> B). Входящие степени: A=0, B=1, C=2, D=1, E=2, F=1, ноль только у A. После A у C степень падает до 1, и очередь пустеет. Выведена только A, у остальных пяти вершин степень так и не стала нулевой. Если в ответе меньше вершин, чем в графе, значит есть цикл.

Для графа с циклом топологического порядка не существует: B должна идти раньше C (ребро B -> C), C раньше E, E раньше F, а F раньше B. Это противоречие. Поэтому топологическая сортировка заодно проверяет граф на ацикличность. Например, сборщик проектов так находит циклическую зависимость между модулями.
