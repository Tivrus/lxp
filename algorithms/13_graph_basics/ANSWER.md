# Графы: основные понятия

Граф V = {A, B, C, D, E}, E = {AB, AC, BC, BD, CE}, неориентированный. Рисунок в graph.svg:

```
A ----- B ----- D
 \     /
  \   /
    C
     \
      E
```

| Вопрос | Ответ |
|---|---|
| Порядок (число вершин) | 5 |
| Размер (число рёбер) | 5 |
| Степени | A = 2, B = 3, C = 3, D = 1, E = 1 (сумма 10 = 2*|E|) |
| Маршрут | A - B - C - A - B - D (вершины и рёбра могут повторяться) |
| Простой путь | A - B - D (вершины не повторяются) |
| Цикл | A - B - C - A (замкнутый, без повторов рёбер и промежуточных вершин) |
| Связный? | да, из A достижимы все вершины |
| Кратчайший путь A -> E | A - C - E, 2 ребра (BFS) |

Список смежности:

```
A: B, C
B: A, C, D
C: A, B, E
D: B
E: C
```
