# Чем отличаются BFS и DFS

Граф V = {A, B, C, D, E}, E = {AB, AC, BC, BD, CE}, соседи перебираются по алфавиту, старт в A.

- BFS: A -> B -> C -> D -> E
- DFS: A -> B -> C -> E -> D

BFS (поиск в ширину) использует очередь (deque): первым пришёл, первым обработан. Сначала просматриваются все соседи стартовой вершины, потом соседи соседей, то есть граф обходится "слоями" по расстоянию от старта. Поэтому BFS в невзвешенном графе находит кратчайший путь по числу рёбер. Памяти нужно столько, сколько вершин в самом широком слое.

DFS (поиск в глубину) использует стек (явный или стек вызовов рекурсии): последним пришёл, первым обработан. Он идёт как можно глубже по одной ветке (A -> B -> C -> E) и возвращается назад только в тупике, после чего берёт следующую ветку (D). Кратчайших путей DFS не гарантирует, зато удобен для поиска циклов, топологической сортировки, компонент связности и проверки достижимости. Памяти нужно на глубину самой длинной ветки.

Обе версии посещают каждую вершину один раз (массив или множество visited) и работают за O(V + E).
